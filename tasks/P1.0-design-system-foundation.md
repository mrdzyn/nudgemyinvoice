- **Status:** Review

## Objective

Add a reusable, platform-aware design-system and product-release readiness foundation to the master project template without embedding proprietary third-party UI kits.

## Context

Phase 0 is merged into `main`. Phase 1 adds the product-experience layer so generated and brownfield-adopted projects can begin UI work with consistent design foundations, platform references, component/state expectations, accessibility requirements, and Figma handoff practices.

PR #2 was rebuilt from finalized `main` after Phase 0 was squash-merged so that Phase 1 preserves all approved Phase 0 security, release, CI, greenfield, and brownfield controls.

## Forbidden scope

- copying Apple, Google, Figma, or other proprietary UI-kit files into the repository;
- selecting a mandatory visual brand for all generated projects;
- adding application-framework dependencies;
- implementing product UI code;
- weakening or reverting approved Phase 0 security, release, CI, or human-gate controls;
- removing the approved brownfield adoption workflow.
