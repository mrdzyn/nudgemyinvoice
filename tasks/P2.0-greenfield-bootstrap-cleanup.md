## Objective

Apply the two greenfield bootstrap improvements discovered during the first real template smoke test with `mrdzyn/wordpress-mcp`:

1. generated projects must remove inherited master-template PROJECT-MEMORY entries during initialization; and
2. generated projects must remove the master-only Template Integrity workflow during initialization.

## Context

The first greenfield smoke test proved that GitHub template creation copied the finalized repository tree correctly and that Project Baseline fails closed while a generated repository remains in `repositoryMode: "template"`.

It also exposed two cleanup requirements that should be enforced when a generated repository transitions to `repositoryMode: "project"`.
