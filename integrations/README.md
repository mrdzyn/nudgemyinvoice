# Third-Party Integration Guides

These guides define reusable integration boundaries for services commonly used across projects.

They are **conditional capability packs**. Do not load or implement one merely because it exists in the master template.

- `revenuecat.md` — in-app/web purchase entitlement orchestration.
- `freemius.md` — SaaS, desktop/app, and WordPress monetization/licensing.
- `paddle.md` — future/reference Paddle Billing integration guide.

Select integrations in `config/project-profile.json`.

Every integration task must still follow project-specific security, privacy, architecture, testing, and release requirements.
