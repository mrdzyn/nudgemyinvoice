## Cross-check gate

- [ ] Privacy Policy describes actual data practices.
- [ ] Store declaration describes first- and third-party SDK/service behavior.
- [ ] Runtime permissions match declared purposes.
- [ ] Data not collected is not silently collected by analytics/ads/AI SDKs.
- [ ] Retention/deletion behavior is documented and implemented.
- [ ] Account/data deletion requirements are implemented where applicable.
- [ ] Children's/minors' data handling is identified where relevant.
- [ ] AI integrations are included in the data-flow review.
- [ ] Privacy declaration was re-reviewed after dependency/SDK changes.
